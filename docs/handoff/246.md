## Contrato

```csharp
static class QuestionDraftOutputParser
{
    const int MaxBytes = 64 * 1024;
    static readonly QuestionDraft MalformedItem;                 // marca de item fora do formato: ("", [], -1, "")
    static IReadOnlyList<QuestionDraft> Parse(string? output);   // lança QuestionDraftGenerationException(InvalidOutput)
}
```

- Formato esperado: `{"questoes":[{"enunciado","a","b","c","d","correta","explicacao"}]}` (ADR-0004 §6.3). As alternativas viram a lista na ordem `a`–`d`.
- **Invalida o lote inteiro** (`InvalidOutput`, sem exceção interna e sem repetir o texto; a `JsonException` cita trechos do texto e por isso não segue junto): nulo ou vazio, acima de 64 KB em UTF-8, JSON inválido, raiz que não é objeto, raiz com propriedade além de `questoes`, `questoes` que não é lista, aninhamento além de quatro níveis.
- **Invalida só o item**, que vira `MalformedItem`: item que não é objeto; propriedade desconhecida, ausente ou repetida; valor que não é texto (inclusive `correta` como lista); texto com escape de par substituto quebrado (o `GetString` do `System.Text.Json` lança nesse caso).
- `correta` é aparada e comparada sem diferenciar maiúsculas (a saída estruturada pode trocar a capitalização de um `enum`). Fora de `a`–`d`, inclusive `"a,b"`, o índice fica `-1`.
- **Não apara, não limpa e não filtra** enunciado, alternativas nem explicação. O lote sai com o mesmo número de itens que entrou.

## Decisões tomadas sem humano

- **Dividir a #236:** analisador aqui, validador e deduplicação lá.
- **`correta` é aparada antes de virar índice**, embora o analisador não apare os textos: ela não é texto a exibir, é a letra que escolhe a alternativa, e a saída estruturada pode devolver um `enum` com capitalização diferente. Enunciado, alternativas e explicação continuam intactos.
- **A leitura da chave do item é protegida** (revisão do PR #247, B1): tanto `property.Name` quanto `NameEquals` lançam `InvalidOperationException` quando a chave traz escape de par substituto quebrado; o item vira `MalformedItem`.
- **Item fora do formato vira uma marca dentro do lote**, em vez de o analisador devolver contadores à parte: a porta devolve só `QuestionDraft`, e assim a contagem dos descartados fica num lugar só (o validador). A marca é uma instância única, reconhecida por referência, e não carrega nada do texto recebido.
- **Raiz com propriedade a mais invalida o lote**, não só o item: com saída estruturada isso não acontece; se acontecer, a resposta inteira é suspeita.
- **Profundidade máxima 4** (raiz, lista, item e um nível): um valor aninhado dentro de um item derruba só o item; mais fundo que isso, o lote.
