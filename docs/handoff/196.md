# Handoff #196 — a dica do mapa de calor não some ao focar uma célula fora da tela

Fix (item 26 de #188). PR empilhado sobre #198.

## Causa
`painel.js` ligava `scroll` direto a `esconder()`. O Tab numa célula fora da tela abre a dica (posição calculada no `focus`), o navegador rola a página até a célula (rolagem **suave**: o Bootstrap põe `scroll-behavior: smooth` em `:root`) e o `scroll` apaga a dica. Medido: 38 Tab, `scrollY` 0 → 1933.

## Correção (só no módulo de dicas, `wwwroot/js/painel.js`, +14/-2)
- Cada `[data-tip]` guarda, no `focus`, `alvoFoco = { alvo, on }` e o instante (`focoEm`); o `blur` limpa e esconde.
- `scroll`: se o alvo ainda é o `document.activeElement` e a rolagem veio até 400 ms depois do último evento do foco, **reposiciona** a dica (`alvoFoco.on()`) e renova a janela (a rolagem suave pode durar mais que 400 ms); senão, `esconder()` como antes.
- `wheel`, `touchmove` e `keydown` zeram a janela: rolagem do usuário volta a esconder. O Tab seguinte abre janela nova no `focus`.
- Esc, `blur`, `pointerleave` iguais. Sem `innerHTML`, biblioteca ou script inline; nenhuma animação nova (`prefers-reduced-motion` intacto).
- O gráfico de linha (`.linechart`) e os indicadores (`.spark`, sem dica) não mudam: o gráfico não registra `alvoFoco`, então o `scroll` o esconde como antes. Só `Dashboard/_Calor.cshtml` usa `[data-tip]`. Observação: o gráfico de linha tem o mesmo problema se estiver fora da tela ao receber foco; não foi pedido e ficou como estava.

## Teste
O projeto não tem infraestrutura de teste de JavaScript (não criei). `PainelScriptTests.Rolagem_causada_pelo_foco_reposiciona_a_dica_em_vez_de_escondela` trava a forma do código servido: o `scroll` não é mais `esconder` direto, confere `activeElement`, reposiciona e mantém `else esconder()`, e roda/toque/tecla encerram a exceção. Falha no `painel.js` antigo (confirmado) e passa no novo.
