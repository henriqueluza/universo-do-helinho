## O que mudou
- Um único `<form method="post">` com três `fieldset.step`. Tipo de quiz = `.theme-pick` (rádios `Input.QuizType`, nome + personagem, imagem com `width`/`height` e `alt=""`); faixa etária = `.pill-pick` (rádios `Input.AgeBand`); alternativas `.alts/.alt` com rádio `Input.Correct` ("Certa"); `.maker-bar` (Salvar, Cancelar).
- Erros: `#resumo-erros` (`role="alert"`, `tabindex="-1"`, `autofocus`) com links; cada campo com `aria-invalid` + `aria-describedby="Input_X-erro"` (nos rádios, em cada um do grupo). O primeiro rádio de cada grupo leva o id `Input_QuizType` / `Input_AgeBand` / `Input_Correct` (alvo do link do resumo).
- Prévia do celular no servidor, com o que está no formulário (salvo, ou enviado quando há erro). `aria-hidden="true"` (repete o formulário); a lista `.ready` ("O que falta") fica exposta com "(feito)"/"(falta)". Tudo codificado pelo Razor (teste com `<script>`).
- Textos atuais mantidos; explicação continua obrigatória (a preview dizia opcional).

## Divergências da preview
- Sem IA, sem "Onde aparece no jogo"/"Só no evento", sem "Salvar e aprovar" (o backend salva só como rascunho).
- Sem `.count-hint` (exige JS); entra "Até 500 caracteres.". Prévia não atualiza ao digitar: rótulo "mostra o que está no formulário". **Prévia ao vivo: #160.**
- Rádios não vêm pré-marcados em questão nova. Dica "Fica como rascunho até ser aprovada" no lugar de "Tudo pronto para salvar".
- O `h1` vem do layout (antes do `.back`).

## O que falta de CSS (seletores; nada editado aqui)
- `.alert { max-width: 400px }` (feito para o Entrar): o resumo de erros do criador fica com 400 px. Sugestão: `.maker-form .alert { max-width: none }`.
- `.phone` sem tema (questão nova sem tipo): `--qb`/`--q` indefinidos, tela escura sem degradê. Sugestão: reservas `var(--qb, var(--canvas))` em `.phone .screen`/`.gq`.
- `.alt .correct` (rádio "Certa") com ~20 px de alvo (WCAG 2.2: 24 px): `min-height: 24px`.
- `.maker-bar` sticky com ~107 px no celular (3 linhas): sugestão `.hint` fora da barra no celular.
- `.main` com grid `1fr` deixa tabela alargar a página (afeta as listas; ver #162).
