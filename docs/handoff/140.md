## Decisões
- **Gaveta = offcanvas do Bootstrap** (`.rail.offcanvas-md`, `data-bs-toggle="offcanvas"`, `id="menu"`), estilizado pelo Recreio: foco preso, Esc, devolução do foco ao botão e `aria-modal`/`role=dialog` vêm de graça (verificado no navegador). A preview usava `.menu-btn` + `.scrim` + `body.menu-open` (do `painel.js`). Para o módulo de gaveta do `painel.js` NÃO agir também: o botão tem a classe `.menu-toggle` (mesmo visual que `.menu-btn`) e não existe `.scrim`; o módulo sai cedo (`if (!btn || !scrim) return`). **Ao ligar o `painel.js`, não crie `.menu-btn`/`.scrim` na casca**; o módulo de gaveta fica inerte de propósito (pode ser removido do script). O `.rail-close` existe (`data-bs-dismiss`), o `painel.js` só o usa se houver scrim.
- **Tema:** botão `button.tema-btn[data-tema][aria-pressed="false"]` ("Tema escuro") no rodapé do menu, visível sempre. Sem script inline. Esconder até `html.js` não é possível: o `painel.js` só põe `js` quando há seção abaixo da dobra e sem movimento reduzido. Alternativa adotada: `@media (scripting: none) { .tema-btn { display: none } }` (sem JS, some). Com o `painel.js` ligado (rodada 1 da revisão, B2), o botão alterna claro/escuro e guarda a escolha em `localStorage['tema']`.
- **Flash de tema claro** (usuário no escuro): `wwwroot/js/tema.js`, externo, pequeno e bloqueante no `<head>` antes do `theme.css`, só lê `localStorage['tema']` (aceita `light`/`dark`) e põe `data-theme` em `<html>`. Sem inline e sem nonce. O `painel.js` com `defer` sozinho deixaria o flash; ele ainda reaplica o mesmo valor (inofensivo) e cuida do botão.
- **Topbar** mora no `_Layout` (não depende de usuário); o componente `PanelUser` renderiza só o `<aside class="rail">`. Estrutura: `.shell > aside.rail + div > (header.topbar + main.main)`.
- `NavItem(Label, Path, Icon, Tile, Group?, MasterOnly)`; grupos: sem rótulo (Dashboard, Alunos, Desempenho), "Conteúdo do jogo" (Questões, Missões, Eventos), "Gestão" (Unidades, Administradores, só Master). Ordem do menu mudou para a da preview. O rótulo "Dashboard" foi mantido (a preview diz "Painel"); trocar é decisão de conteúdo. "Curiosidades" não foi criado.
- Ícone do menu: `<svg><use href="#i-...">` (sprite `_Icones`), 16 px, traço 1,9.

- Novos (não existem na preview): `.menu-toggle`, `.tema-btn`, `.rail-foot`, `.rail nav` (gap), `.rail { color }`, `.main > .page-title { margin-bottom: 0 }` (a ponte do legado somava 24 px ao gap de 24 px da `.main`), `.skip-link` com tokens do Recreio.

## Classes que as telas devem usar dentro de `.main`
`.main` é um grid de uma coluna com `gap: 24px` (filhos diretos = seções). O `h1.page-title` é do layout. Cada seção da tela deve ser filho direto de `.main` (o `painel.js` aplica `.reveal`/`.vis` aos filhos diretos e a entrada em cascata usa `:nth-child`). Tabela larga: `.card-panel:has(> .table)` (ponte do #138) rola por dentro.
