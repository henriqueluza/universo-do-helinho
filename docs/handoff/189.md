Parte de #188. Base `base/recreio-telas`. O handoff completo da Issue-mãe fica em `docs/handoff/188.md` (PR final).

## O que mudou
- `theme.css`: foco do `.select`/`.input` volta a usar o anel global `--focus` (tirado o `outline: none`); `:is(.input, .select)[aria-invalid="true"]` com borda vermelha; `.alt .correct` com `min-height: var(--h-control)`; número do mapa de calor visível em `:focus-visible` e com cor escolhida pela luminância da célula (`--cell`); `position: relative` em `.table-wrap` e `.tscroll`; `.two > * { min-width: 0 }`; `.check input { flex: none }`; classes novas `.form-sm`, `.form-md`, `.meter-inline`, `.attn .ic-warn/-neutral/-q`, `.feed .av.<tipo>`, `.face-solo.con`.
- Marcação: saem `style="min-width:0"` (5), `style="position:relative"` (2), `overflow-hidden` (Questões), `style` de formulários de Unidades/Administradores, do medidor da ficha, do ícone de alerta, do avatar do feed e do rosto do Acesso negado. `IndexModel.AlertStyle` virou `AlertTone` (classe).
- Testes: `PainelSemStyleInlineTests` (4); `ContaRecreioTests` (o Entrar agora carrega `tema.js`/`painel.js`; script inline segue proibido); `DashboardRecreioTiposTests` (classe do ícone).

## Decisão sem humano
O critério "nenhuma página fica com `style=`" foi lido como "nenhum `style=` de layout, cor ou posição". Ficam só variáveis CSS por instância (`--t`, `--v`, `--x`...) e `width: N%` de barra de dado, que só o servidor conhece. Remover esses também exigiria `attr()` tipado (sem suporte no Safari) ou JS: Issue de continuação própria.
