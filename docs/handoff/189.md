## Decisão sem humano
O critério "nenhuma página fica com `style=`" foi lido como "nenhum `style=` de layout, cor ou posição". Ficam só variáveis CSS por instância (`--t`, `--v`, `--x`...) e `width: N%` de barra de dado, que só o servidor conhece. Remover esses também exigiria `attr()` tipado (sem suporte no Safari) ou JS: Issue de continuação própria.
