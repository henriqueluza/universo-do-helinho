## Contrato (o que as próximas Issues consomem)

```csharp
interface IQuestionDraftGenerator
{
    Task<QuestionDraftBatch> GenerateAsync(QuestionDraftRequest request, CancellationToken cancellationToken);
}

record QuestionDraftRequest(QuizType QuizType, AgeBand AgeBand, int Count, string? Subject,
                            IReadOnlyList<string> ExistingStatements);   // MaxCount = 20, SubjectMax = 120
record QuestionDraft(string Statement, IReadOnlyList<string> Options, int CorrectIndex, string Explanation);
record QuestionDraftBatch(IReadOnlyList<QuestionDraft> Drafts, string PromptVersion, AiUsage Usage);
record AiUsage(string Provider, string Model, int InputTokens, int OutputTokens, TimeSpan Duration,
               string? ProviderRequestId = null);

enum QuestionDraftFailure { Timeout, ProviderUnavailable, RateLimited, Refused, InvalidOutput, Misconfigured, Disabled }
class QuestionDraftGenerationException(QuestionDraftFailure reason) { QuestionDraftFailure Reason }
```

- **`QuestionDraftRequest.Create(...)` é o caminho de produção.** Rejeita (com `DomainException`, mensagem em português que não repete o que foi digitado) tipo ou faixa indefinidos, quantidade fora de 1–20 e assunto inválido; copia a lista de enunciados. O construtor público continua existindo para os testes montarem casos inválidos (ADR-0004 §4).
- **`QuestionDraftRequest.SanitizeSubject(string?)`** é público para o montador da requisição reaplicar o saneamento em requisição que não veio da fábrica. Ordem: controles, espaços de qualquer tipo, invisíveis e de direção (categoria `Format`), substitutos soltos, uso privado e não atribuídos viram espaço; normalização KC (desdobra `＜` em `<`); `<` e `>` saem; espaços repetidos viram um; acima de 120 caracteres, com `@` ou com seis dígitos seguidos, **rejeita**. Assunto que fica vazio vira `null`.
- **`ToString`** da requisição e do rascunho devolve só o nome do tipo: assunto, enunciados e texto gerado não vazam por log nem por interpolação.
- **O lote não é filtrado pelo gerador.** Quem decide o que presta é o validador (Issue própria).
- **A exceção só carrega o motivo.** Não tem construtor com exceção interna de propósito: a exceção de um SDK pode trazer corpo de resposta.

## Decisões tomadas sem humano

- **Dividir a Issue.** "Porta, tipos e opções" mediu 541 linhas; as opções `Ai:*` e o registro foram para a #227. Alternativa descartada: cortar testes para caber em 400.
- **Motivo `Disabled` a mais** em relação à lista do ADR-0004 §4. É o que o gerador desligado (#227) devolve; `Misconfigured` diria "avise o responsável técnico" para uma IA que está desligada de propósito. Alternativa descartada: `InvalidOperationException`, que o trabalhador trataria como defeito e repetiria.
- **Os tipos ficam num arquivo só**, ao lado da porta: são o contrato dela e somam 127 linhas.
- **Substituto solto vira espaço** antes da normalização: `string.Normalize` lança `ArgumentException` com par quebrado, e o erro subiria como 500. O efeito colateral é que emoji no assunto também vira espaço, o que não faz falta.
- **"Seis dígitos seguidos" ao pé da letra do ADR-0004 §11.** Telefone ou CPF digitado com pontuação passa por essa regra; o risco residual do campo livre já está registrado no ADR (seção 11) e vai para o runbook.
- **QA e documentação feitos nesta sessão**, sem os subagentes `qa-tester` e `docs-writer` do `implement-issue`: o dono pediu pressa e a revisão automática do PR roda o `qa-tester`. O mapa critério → teste está no PR.
