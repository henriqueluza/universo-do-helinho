## Contrato

```csharp
enum DraftRejection { Malformed, OverLimit, Incomplete, WrongOptionCount, InvalidCorrectIndex,
                      DuplicateOptions, TooLong, UnsafeText, Duplicate }

record QuestionDraftValidation(IReadOnlyList<QuestionDraft> Accepted, IReadOnlyDictionary<DraftRejection, int> Rejections)
{ int DuplicateCount; int InvalidCount; }                               // os dois contadores do job (ADR-0004 §9.2)

static class QuestionDraftValidator
{
    static QuestionDraftValidation Validate(IReadOnlyList<QuestionDraft> drafts, IEnumerable<string> existingStatements, int limit);
    static string Normalize(string statement);
    static Task<IReadOnlyList<string>> ListExistingStatementsAsync(IAppDbContext db, QuizType quizType, AgeBand ageBand, CancellationToken ct);
}
```

**Como usar (caso de uso do trabalhador):** `existing = ListExistingStatementsAsync(db, tipo, faixa)` → montar a requisição com `existing` → `batch = gerador.GenerateAsync(...)` → `Validate(batch.Drafts, existing, request.Count)` → gravar só `Accepted`, com `InvalidCount` e `DuplicateCount` no job. Quando a tabela de sugestões existir, some os enunciados das sugestões guardadas a `existing`; e rode a deduplicação de novo na aprovação (ADR-0004 §8).

### Validador (um motivo por rascunho, nesta ordem)

| Motivo | Regra |
|---|---|
| `OverLimit` | posição além da quantidade pedida (nunca além de 20) |
| `Malformed` | item que o analisador marcou |
| `WrongOptionCount` | não tem exatamente 4 alternativas |
| `Incomplete` | enunciado, explicação ou alternativa vazios depois de aparar |
| `InvalidCorrectIndex` | índice da correta fora de 0 a 3 |
| `DuplicateOptions` | duas alternativas iguais depois de normalizadas |
| `TooLong` | acima de `SaveQuestion.StatementMax` (500), `ExplanationMax` (1000) ou `OptionMax` (300); rejeita, não corta |
| `UnsafeText` | caractere de controle (inclusive quebra de linha), invisível ou de direção, uso privado, não atribuído ou par substituto quebrado; `<` seguido de letra, `/` ou `!`; `http://`, `https://` ou `www.` |
| `Duplicate` | enunciado normalizado igual a um existente ou a um já aceito no mesmo lote |

- **Normalização:** minúsculas invariantes, sem acentos, o que não é letra nem dígito vira espaço, espaços repetidos viram um.
- **Um rascunho inválido não ocupa o enunciado:** a duplicata é a última regra.
- **Os aceitos saem aparados.** O texto rejeitado não é guardado nem vai para log.
- `<` seguido de espaço ou número ("3 < 5") e emoji em par válido passam.

## Decisões tomadas sem humano

- **O limite é a quantidade pedida**, não só 20 (o ADR-0004 §8 fala em "mais de 20 itens"): a cota é contada em sugestões pedidas, então aceitar mais do que foi pedido furaria a cota.
- **A consulta do que já existe é um método estático do validador** (`ListExistingStatementsAsync`), no padrão dos casos de uso que consultam `IAppDbContext` direto (concessão 1 do ADR-0001). Sem repositório novo.
- **Similaridade aproximada não entra** (ADR-0004 §8): só a forma normalizada.
- QA e documentação feitos nesta sessão, sem os subagentes `qa-tester` e `docs-writer`.
