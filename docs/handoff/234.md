## O que mudou
`src/Helinho.Application/Abstractions/IJobHandler.cs`, sem tipo de framework:

```csharp
public interface IJobHandler
{
    IReadOnlyCollection<string> Types { get; }
    JobPolicy Policy { get; }
    Task<JobResult> HandleAsync(JobContext job, CancellationToken cancellationToken);
}

public interface IAbandonedJobHandler
{
    Task OnAbandonedAsync(JobContext job, string reason, CancellationToken cancellationToken);
}

public sealed record JobContext(
    Guid Id, string Type, Guid? SubjectId, JsonElement Payload, int Attempts, DateTimeOffset CreatedAt, DateTimeOffset ExpiresAt);

public sealed record JobPolicy(
    int MaxAttempts, TimeSpan MinBackoff, TimeSpan MaxBackoff, int BatchSize, TimeSpan ItemTimeout, TimeSpan Lease);

public abstract record JobResult   // construtor privado: só as quatro formas abaixo
{
    public sealed record Succeeded(string? ExternalId = null) : JobResult;
    public sealed record Retry(string ErrorCode, DateTimeOffset? NotBefore = null) : JobResult;
    public sealed record Fail(string ErrorCode) : JobResult;
    public sealed record Suspend(string ErrorCode, TimeSpan PauseFor) : JobResult;
}
```

## Decisões tomadas sem humano
- **Nomes e assinaturas iguais aos do ADR §6.6 e §6.7.** O ADR diz que são ilustrativos e que a Issue 1 os fixa; não havia motivo para mudar.
- **`JobResult` como registro abstrato com quatro registros aninhados e construtor privado**: o trabalhador trata os quatro casos com `switch` e ninguém cria um quinto fora do tipo. O ADR só descreve as formas em comentário.
- **Códigos de erro validados no construtor** (`JobCode.Require`, da #223): `Retry`, `Fail` e `Suspend` recusam mensagem livre, para que texto de exceção, endereço ou link nunca cheguem à coluna `LastError`.
- **`ExternalId` não é validado**: é o identificador devolvido pelo provedor (o `messageId` da Brevo tem arroba). O trabalhador limita a 200 caracteres ao gravar.
- **`JobPolicy` sem validação própria**: `BatchSize × ItemTimeout ≤ Lease` é conferido na subida pelo trabalhador (#228), como diz o ADR §6.1.
