# Handoff #125: painel.js

## Estado
`src/Helinho.Web/wwwroot/js/painel.js` pronto, ainda não referenciado por nenhuma página (a casca o liga com `<script src="~/js/painel.js" defer>`). Teste: `tests/Helinho.IntegrationTests/PainelScriptTests.cs`.

## Contrato de marcação (cada módulo sai cedo se o elemento não existe)
| Módulo | Espera | Observações |
|---|---|---|
| Tema | `[data-tema]` (botão, qualquer página) | Aplica `localStorage['tema']` (`light`/`dark`) em `<html data-theme>` ao carregar, mesmo sem botão. Atualiza `aria-pressed` no botão. Revelação circular por View Transitions só com movimento. |
| Números | `[data-count="N"]` com o valor final já no texto | Sem JS ou com movimento reduzido nada muda. |
| Gaveta | `.menu-btn`, `.scrim` (com `hidden`), `.rail-close`, `.main`, `.topbar`; `body.menu-open` | Tira `hidden` do scrim; põe `inert` em `.main` e `.topbar`; fecha com Esc, scrim, X ou ao passar de 768 px. |
| Cena do login | `.auth-scene` | Define `--mx`/`--my` (só mouse, sem redução). |
| Entrada das seções | `.main` com filhos diretos | Aplica `.reveal`/`.vis` e a classe `js` em `<html>` (só se houver seção abaixo da dobra e sem redução). O CSS esconde só `.js .main > .reveal:not(.vis)`. |
| Minigráfico | `svg.spark[data-spark="v1,v2,..."]` (>= 2 números) | Cria `g > path.s-area + path.s-line`. |
| Gráfico de linha | `.linechart[data-fonte="<id da tabela>"]` com `tabindex="0"`; tabela com `thead` (cabeçalhos de col. 2 e 3 viram nomes na dica) e `tbody` com 3 células por linha (`th[data-curto]`, `td`, `td`), >= 2 linhas | Setas, Home, End, Esc. |
| Dicas | `[data-tip="Título\|linha\|linha"]` | Mouse e foco. A dica `.tip` só é criada se houver gráfico, minigráfico ou `[data-tip]`. |

## Para a casca
- O `<script>` inline do `<head>` da preview (`classList.add('js')` + tema) NÃO deve ser copiado: viola CSP e `painel.js` já faz as duas coisas. Efeito: com `defer` pode haver um flash do tema claro ao abrir no escuro; se incomodar, decidir entre um script externo bloqueante minúsculo ou nonce (fora desta Issue).
- Botão do tema fica dentro de `<details class="pv">` na preview; na casca real precisa estar visível.

## Decisões sem humano
- Mantive a cena do login seguindo o mouse (decorativa, estava na preview, não está na lista de saídas).
- Removi o estado "ocupado" do botão de login (faz parte do envio simulado); se a tela de login quiser um girador, é Issue própria.
- SVG dos gráficos por `createElementNS` (a preview usava `innerHTML`); estilos só via CSSOM (`style.translate`, `style.setProperty`), permitidos sem `unsafe-inline`.
