# Handoff #24 — logout da API

**Estado:** `POST /api/logout` (P3) revoga no servidor a sessão do token apresentado e responde 204 sem corpo. Token inválido, vencido ou já revogado responde 401 `token_expired` (esquema Bearer ou handler), sem 500. 169 testes passam.

**Decisões**
- `LogoutHandler` (Application) calcula o hash do token e chama `ApiSession.Revoke`; só a sessão do token é afetada (outras sessões do aluno seguem válidas).
- O endpoint lê o token do cabeçalho `Authorization`; o `ApiBearerHandler` continua sendo a única validação em todas as rotas, então o token revogado cai em 401 em qualquer rota.
- Sem migração, DTO novo ou pacote novo.
